# Safety and security

Byte Bunny is voluntary. The campaign page does not mine automatically, install software, request a wallet secret, or retain visitor data.

Only download mining software from the official Quantus pool links in the README. Verify the published SHA-256 checksum before running a native binary. Stop if a device becomes uncomfortably hot or unstable.

Please report a security concern through a private GitHub security advisory rather than a public issue. Never include private keys, seed phrases, passwords, SSH keys, or machine credentials in a report.
